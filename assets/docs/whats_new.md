# What’s New in v1.0.0

### Workspace
- Added a desktop menu with hover-driven cascading menus.
- Added a central quick-action overlay with side-by-side document comparison.
- Added undo and redo for applied working-copy changes.
- Added compact document actions and improved page selection controls.

### Languages
- Added British English, Setswana, Hindi, Mandarin Chinese and Arabic language choices.
- Language selection is available during first launch and from the app menu.
